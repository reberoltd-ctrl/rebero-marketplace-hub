# REBERO Roadmap

## Stage 1–2 (this round)
- [ ] Database: roles, profiles, categories, districts, shops, products, images, wishlists, settings, audit log
- [ ] Sign up / sign in (email + Google), password reset
- [ ] Super Admin bootstrap (admin@rebero.rw, password from SUPER_ADMIN_INITIAL_PASSWORD) + forced password change
- [ ] Storefront: header, homepage sections, product cards, search & filters, category pages
- [ ] Product page with gallery, specs, share (WhatsApp/Facebook/copy), real product image in link previews, ?ref capture
- [ ] Labelled sample products under a "REBERO Demo" shop (user asked)
- [ ] Wishlist, customer account page
- [ ] Seller application + seller dashboard (products with image upload, pending approval)
- [ ] Super Admin: overview from real data, approve sellers/products, categories, users & roles

## Later stages
- [ ] Cart, checkout, multi-seller orders, seller-managed delivery statuses
- [ ] Commission engine (2% seller / 1% affiliate, configurable) + tests
- [ ] Affiliate programme: applications, last-click attribution, dashboard, payouts
- [ ] Rwanda payments (MTN MoMo / Airtel Money) — needs provider credentials
- [ ] Reviews, notifications, support & disputes
- [ ] Subscriptions, ads/featured listings, reports & CSV export
- [ ] Kinyarwanda language, PWA, legal pages, docs
